# Optimum Racing website (concept)

Static site, no build step. Open `index.html` or deploy on GitHub Pages.

- `css/style.css` shared styles, `js/main.js` shared behaviour (all pages)
- `images/team/*.svg` placeholder avatars, `images/gallery/*.svg` placeholder photos: replace with real files of the same name (or edit the `<img>` paths)
- All people, sponsors and results are fictional placeholders
